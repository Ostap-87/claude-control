## 4. ПРОЦЕДУРЫ (коротко)
═══════════════════════════════════════════════

НОВЫЙ ЧАТ С ИИ:
1) Прикрепи docs/МЕДИАСИСТЕМА.md (этот файл-пара — рядом)
2) Если чат про конкретный сайт — добавь его PULT.md
3) Скажи: «работаем по протоколу пульта»

ПУБЛИКАЦИЯ СТАТЬИ:
Материалы → ИИ собирает paste-блок → вставить в tmux → готово.
(Правила форматов — в PULT.md соответствующего сайта)

ПОТЕРЯЛ ДОСТУП К СЕРВЕРУ:
1) cloud.reg.ru → веб-консоль (VNC) → вход root
2) Починить ssh / посмотреть логи: journalctl -u ssh

ПОМЕНЯЛ ДОКУМЕНТ:
Правка → git add/commit/push в claude-control → на Mac и сервере git pull.
На Mac документы: ~/Documents/Проекты/МЕДИАСИСТЕМА/

ПРОВЕРКА ЗДОРОВЬЯ СИСТЕМЫ (ежедневно, 30 сек):
tail -5 /var/log/content-pipeline.log   — конвейер
